Privacy

Yours, and only yours.

Cortex runs on your Mac. No account, no analytics, no servers of ours.

  • Screen memory is off by default, pauses with ⌘⇧P, skips password fields and never records the apps you block.
  • API keys and tokens stay in files only you can read, and are never included when you export settings.
  • AI suggestions never run a command without you pressing Enter.
  • Lyrics come from lrclib.net and weather from Open-Meteo — only the song name or your rough location is sent.

If macOS says it can't check the developer, run xattr -cr /Applications/Cortex.app once, or use Open Anyway in Privacy & Security.

Grant

Settings → Privacy & Permissions → Grant everything. Accessibility and Screen Recording you switch on yourself.

Why does macOS warn me the first time?

Cortex isn't notarized by Apple (that needs a paid developer account). Every release is signed with the same certificate, so once you allow it, updates and permissions carry over.

Does it replace the macOS Dock?

It hides the system Dock while Cortex runs and puts it back when you quit. You can turn the Cortex Dock off any time.

Which music apps work?

Anything that shows up in macOS's Now Playing: Apple Music, Spotify, YouTube in a browser, VLC and more.
